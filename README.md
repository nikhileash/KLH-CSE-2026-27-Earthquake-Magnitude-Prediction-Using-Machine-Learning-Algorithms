# Machine Learning-Based Earthquake Magnitude Prediction

## Project Overview

This project uses machine learning techniques to predict earthquake
magnitude based on historical earthquake data.

## Objectives

- Collect historical earthquake data
- Preprocess seismic data
- Perform exploratory data analysis
- Train machine learning models
- Predict earthquake magnitude
- Evaluate model performance

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Machine Learning

## Dataset

The dataset contains earthquake-related parameters such as:

- Latitude
- Longitude
- Depth
- Time
- Seismic measurements
- Magnitude

## Methodology

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Selection
5. Model Training
6. Model Evaluation
7. Magnitude Prediction

## Results

The trained machine learning model is evaluated using
appropriate regression metrics.
